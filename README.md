## 提示词 1：文献综述快速生成
请帮我对以下上传的X篇文献进行系统性综述。我的研究主题是**研究主题**。请按照以下结构生成综述：
1. 研究背景与问题提出（300-500 字）
2. 核心研究主题归类：请将这 [N] 篇文献按研究主题聚类，每个主题下用 2-3 句话总结代表性文献的观点和方法
3. 研究方法比较：请用表格形式，对比各篇文献的研究方法、样本规模、数据来源和主要局限
4. 研究空白识别：基于上述分析，指出目前研究中尚未被充分探讨的 3-5 个问题
5. 未来研究方向建议：对每个研究空白给出可能的研究思路
6. 要求：所有引用必须标注文献作者和年份，格式为（作者，年份）。不要编造文献中的内容，如果不确定，请明确标注"不确定"。

## 提示词 2：论文分析与批判性阅读
请对这篇名为**论文标题**的论文进行深入的批判性阅读。请从以下角度分析：
1. 论文的核心论点和贡献是什么？
2. 研究方法是否恰当？存在哪些方法论的局限性？
3. 数据分析过程是否严谨？有无可质疑之处？
4. 论文的结论是由数据充分支撑的，还是存在过度推断？
5. 这篇论文与同领域的其他研究相比，创新点在哪里？
6. 如果你是一位同行评审专家，你会给出哪些修改建议？请以学术评审的语气撰写，总字数控制在 800-1000 字。

## 提示词 3：长文档精读与笔记
请完整阅读这份**XX**文档。完成后：
1. 生成一份结构化的导读笔记，按章节顺序，每章提炼 3-5 个核心要点
2. 标注文档中反复出现的关键术语，并给出它们在文中的具体含义
3. 找出文档的逻辑主线：作者的核心论证路径是什么？
4. 提取文档中所有具体数据、案例、引用的来源信息
5. 指出文档中论证薄弱或逻辑跳跃的部分要求：笔记需保持客观，区分"作者的观点"和"文档中的事实"。

## 图片转PPT提示词
请使将我提供的这张PPT截图重建为一页对象级可编辑的PowerPoint，并保存为 .pptx。
	
核心要求：
1. 禁止把整张截图直接作为整页背景或整页图片插入 PPT。
2. 页面比例、构图、配色、字体层级、间距和视觉风格尽量与原图一致。
3. 所有标题、正文、标签、数字、脚注和参考文献必须使用独立的 PowerPoint文本框，文字可编辑。
4. 所有边框、卡片、色块、圆形、虚线、分隔线、连接线和箭头必须使用独立的 PowerPoint 原生图形，能够单独移动、修改颜色和调整尺寸。
5. 图案和文字必须分开。图片内部不得保留与可编辑文本重复的标题、标签或说明文字。
6. 无连接关系的图片元素必须拆分为独立图片对象，不得合并成一张大图。
7. 有视觉整体性的复杂插画、人物、器官、脑区、实验图标可作为整体图片，不要求拆解图片内部结构，但每个图案必须是独立、可移动的图片对象。
8. 不得裁掉图像边缘；所有图案必须完整显示，不得拉伸变形。
9. 连接线和箭头先建立，再放置节点、图案和文字，避免线条遮挡内容。
	
对象拆分标准：
- 文字：每个语义块单独文本框。
- 线条：每条连接线、虚线、分隔线独立。
- 箭头：每个箭头独立。
- 图案：每个无连接的器官、人物、图标或插画独立。
- 容器：每个卡片、栏目框、标题条独立。
- 图表：坐标轴、柱形、标签和数值尽量使用原生对象重建。
	
制作完成后必须执行：
1. 导出整页预览图并逐项检查。
2. 检查是否存在图像裁剪、文字换行错误、文字重叠、图形遮挡和线条错位。
3. 检查 PPTX 中是否存在覆盖整页的源截图；若存在则删除并重建。
4. 检查文本框、原生图形和图片对象数量，确认页面确实为对象级拆分。
5. 修正问题后重新导出并再次检查。
	
交付内容：
- 最终可编辑 PPTX 文件。
- 明确说明是否使用了整页截图。
